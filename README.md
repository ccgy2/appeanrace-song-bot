# APPEARANCE — 음악·경기 사운드 컨트롤

현재 수정본: **voice-dependencies-fix-20261124-3**. **[기존 MP3까지 무음인 경우의 음성 라이브러리 수정 안내](UPDATE_VOICE_DEPENDENCIES_20261124.md)를 먼저 읽고 Railway 봇을 새로 빌드·배포하세요.**

`discord.py 2.7.1`과 호환되지 않는 `davey 0.2.0`이 새 배포에 자동 설치될 수 있었던 문제를 수정했습니다. 음성 라이브러리를 `davey==0.1.7`로 고정하고 Docker 빌드에서 조합을 확인합니다. 이전 수정본을 이미 적용했다면 이번 변경은 봇 서버에 적용하면 됩니다. 기존 곡을 다시 등록할 필요는 없습니다.

이전 [무음 재생 수정](UPDATE_PLAYBACK_FIX_20261124.md)도 유지합니다. 여러 음성 트랙이 있는 MP4에서 첫 번째 무음 트랙을 강제로 선택하던 오류를 수정했고, 실제 재생 중 볼륨과 선택한 팀의 볼륨을 구분해 음소거·연결 끊김을 화면에 표시합니다.

파일당 최대 **10GB(10240MiB)**, 오디오 트랙이 있는 **MP4** 등록을 지원합니다. 4MiB씩 전송하고 중단된 요청은 저장된 위치에서 재시도합니다. 큰 파일의 미리듣기·다운로드는 파일 전체를 브라우저 메모리에 담지 않습니다. 기존 Railway Variables에 `MAX_UPLOAD_MB=25`가 남아 있으면 **`10240`으로 바꿔야** 합니다. 전체 저장 한도 기본값은 `MAX_STORAGE_MB=20480`이며, 실제 영구 볼륨에도 충분한 여유 공간이 필요합니다. [이번 검증 결과](TEST_REPORT_UPLOAD_10GB_MP4_20261124.md)를 확인하세요.

등장곡 등록/삭제자와 재생자가 타순을 선택·저장하는 기능과 경기 사운드의 개인 정렬 기능도 포함합니다. 경기 사운드는 `카드 순서 편집`에서 맨 위·위·아래·맨 아래로 이동하며, 내 브라우저에 계정·팀별 순서를 자동 저장합니다. 팀·회원·백업 관리 권한은 관리자에게 유지됩니다. [타순·정렬 안내](UPDATE_LINEUP_SOUND_ORDER_20261030.md)는 이전 기능의 상세 설명입니다.

이전 절약형 설정과 기존 기능은 유지했습니다. 아래는 이전 업데이트 설명입니다.

**[2차 Railway 절약형 적용 안내](RAILWAY_COST_REDUCTION_V2.md)**

1차 최적화에 음성 인코딩 절약형(96kbps, 패킷 손실 보정 끔), 인증 자원 상한, 실제 서버 사용량 진단과 적용 버전 표시를 추가했습니다. Railway Docker/Nixpacks 배포 기본값은 economy이며, 불안정한 네트워크에는 AUDIO_PROFILE=standard를 사용할 수 있습니다. 기존 음원·계정·볼륨 기능은 유지하며 데이터 마이그레이션은 없습니다. [2차 검증 결과](TEST_REPORT_ECONOMY_V2.md)도 함께 제공합니다.

아래는 이전 기능 업데이트 안내입니다.

자동 등장곡 전체 ON/OFF, 등록/삭제자·재생자·유저 권한, 스테이지 발언자 처리, 세 종류 음악 다중 연결/파일 드롭/순서 편집, 기본 상황 삭제·복원, 원본명 오디오 ZIP, 삼성·아이폰 설치형 웹앱(PWA)을 추가했습니다. 별도 APK/IPA가 아니며 아직 운영 서버에 배포된 결과물이 아닙니다.

계정·데이터·Volume을 유지하세요. 테스트 결과와 미검증 항목은 TEST_REPORT_STUDIO.md에 있습니다.

**실제 Railway 볼륨 연결은 코드 배포만으로 생성되지 않습니다.** 기존 볼륨을 보존하거나 봇 서비스에 `/data` 볼륨을 연결하고 `DATA_DIR`를 동일한 경로로 맞추세요. 아직 남아 있는 서버 파일은 배포/볼륨 경로 변경 전에 백업하세요. 이미 없어진 오디오는 원본을 다시 업로드해야 합니다.

봇에는 Python 3.12, FFmpeg/ffprobe와 `requirements.txt` 의존성이 필요합니다. YouTube 링크용 Deno는 기존 Dockerfile에서 설치합니다. 설정은 기존 Railway Variables 또는 비밀 `.env`를 사용하고 공개 저장소에는 넣지 마세요.

```sh
python -m pip install -r requirements.txt
python main.py
```
