웹으로 바로 시작

기기에 맞는 설치 방법을 확인하세요.

별도 APK/IPA 파일이 아닌 설치형 웹앱(PWA)입니다. 인터넷 연결과 실행 중인 봇 서버가 필요합니다.

SAMSUNG · ANDROID

Galaxy에 설치하기

  1. 이 페이지를 Chrome에서 여세요. 카카오톡·Discord 내부 브라우저라면 외부 브라우저로 열어주세요.
  2. 위에 설치 버튼이 나타나면 누르고 설치를 확인하세요.
  3. 버튼이 없으면 브라우저 메뉴에서 앱 설치 / 홈 화면에 추가 항목을 확인하세요. Samsung Internet에서는 홈 화면 추가 메뉴를 확인하세요.
  4. 홈 화면의 APPEARANCE 아이콘을 열고 기존 웹 계정으로 로그인하세요.

이미 설치했다면 홈 화면 아이콘으로 실행하세요. 일반 브라우저 탭에서는 기존 설치 여부를 정확히 판단하지 못할 수 있습니다.

APPLE · iOS / iPadOS

iPhone에 설치하기

  1. 이 페이지를 Safari에서 여세요.
  2. 공유 버튼을 누른 뒤 홈 화면에 추가를 선택하세요. 안 보이면 공유 동작 목록을 확인하세요.
  3. 웹 앱으로 열기 옵션이 표시되면 켜고 추가를 누르세요.
  4. 홈 화면의 APPEARANCE 아이콘을 열고 기존 웹 계정으로 로그인하세요.

아이폰에는 이 페이지의 자동 설치 버튼 대신 Safari의 홈 화면 추가 기능을 사용합니다. OS 버전에 따라 메뉴 위치가 다를 수 있습니다.

계정과 곡을 다시 만들어야 하나요?

아니요. 같은 봇 서버의 기존 계정·권한·라이브러리를 사용합니다. 앱을 처음 열 때 로그인은 다시 필요할 수 있습니다. 설치 과정에서 계정이나 곡을 복사하거나 초기화하지 않습니다.

앱과 웹의 기능이 다른가요?

같은 화면과 API를 사용합니다. 부여된 권한에 따라 재생, 자동 등장곡 ON/OFF, 곡 등록·삭제, 경기 사운드 편집, 백업 기능을 사용할 수 있습니다. 앱이 실제 오디오를 대신 재생하는 것이 아니라 서버의 Discord 봇에 명령을 보냅니다.

인터넷이 끊겼을 때도 재생 명령이 실행되나요?

네트워크가 필요합니다. 오프라인 명령을 저장하거나 나중에 자동 실행하지 않습니다. 업로드·저장 중에는 앱을 닫거나 화면을 잠그지 마세요. 다시 연결한 뒤 최신 상태를 확인하세요.
